# Employee Payroll Salary System

A payroll management system to handle employee records, salary structure and monthly salary processing.

## Tech Stack
- Core Java (JDBC)
- MySQL
- Angular

## Features (Planned)
- Employee CRUD
- Salary structure management
- Monthly payroll generation
- Payslip view

## Status
In Progress

## Setup
1. Run database/schema.sql in MySQL
2. Update DB credentials in backend/src/com/payroll/util/DBConnection.java
3. Run backend
4. cd frontend && ng serve
